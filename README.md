# Game Store API

**Backend-разработчик (Python / FastAPI)** — тестовое задание.

## 📋 Описание проекта

Это API для магазина цифровых товаров (геймерские ключи, пополнения Steam, подписки). 
Система обрабатывает заказы, принимает платежи через вебхуки и осуществляет автоматическую выдачу товара.

**Ключевая особенность:** система спроектирована вокруг принципа **идемпотентности (exactly-once)** — заказ не может быть выдан дважды, даже при получении множества одинаковых (дублирующихся) вебхуков или при сбоях сети.
