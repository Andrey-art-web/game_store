# Game Store API

**Backend-разработчик (Python / FastAPI)** — тестовое задание.

## 📋 Описание проекта

Это API для магазина цифровых товаров (геймерские ключи, пополнения Steam, подписки). 
Система обрабатывает заказы, принимает платежи через вебхуки и осуществляет автоматическую выдачу товара.

**Ключевая особенность:** система спроектирована вокруг принципа **идемпотентности (exactly-once)** — заказ не может быть выдан дважды, даже при получении множества одинаковых (дублирующихся) вебхуков или при сбоях сети.

# Game Store API

Тестовое задание на Backend-разработчика (Python, FastAPI).

## Реализованные задачи:

### ✅ Задача 1: Заказ из нескольких товаров
- В одном заказе может быть несколько SKU.
- Каждый товар выдаётся отдельно.
- Если часть товаров не удалось выдать — остальные выдаются, а неудачные помечаются как `failed`.

### ✅ Задача 2: Защита от недобросовестного поставщика
- Уникальный индекс на `code` в таблице `order_items`.
- Если поставщик выдал повторный код — система это ловит и помечает товар как `failed`.

### ✅ Задача 3: Очередь и лимит поставщика
- Заказы добавляются в очередь с приоритетом.
- Оплаченные заказы обрабатываются первыми (`priority=1`).
- Лимит поставщика (`max_per_minute=10`) не превышается.

### ✅ Задача 4: Восстановление состояния (Event Sourcing)
- Все события по заказу пишутся в журнал `order_events`.
- По запросу можно восстановить состояние заказа или денег на любую дату.
